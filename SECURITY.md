# Security Policy

## Data handling

MBP's Image Padder is a fully local tool. It:

- stores **no** credentials, API keys, tokens, or personal data anywhere
- never sends your photos or any data over the network
- processes images entirely on your machine
- writes output only to the folder you choose (default `~/Desktop/Padded`)

There is nothing to configure, authenticate, or expose — the source photos and their EXIF metadata stay local.

## Reporting a vulnerability

This is a personal project. To report a security issue, open a private discussion or contact the maintainer directly. Do **not** open a public issue that includes tokens, API keys, or credentials.

## Supported versions

Only the latest release is supported.
